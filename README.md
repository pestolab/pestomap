# PestoMap

> shp 파일 폴더만 지정하면, 레이어 세팅부터 지도 출력까지 버튼 한 번에 끝.

---

## 설치 방법

1. 이 페이지 오른쪽 위 **Releases** 클릭
2. `pestomap_v0.1.zip` 다운로드
3. QGIS 실행 → 상단 메뉴 **플러그인 → 플러그인 관리 및 설치**
4. 왼쪽 **ZIP에서 설치** 탭 클릭
5. 다운로드한 ZIP 파일 선택 → **플러그인 설치** 클릭
6. 완료 — QGIS 상단 메뉴에 **PestoMap** 항목이 생겨요

---

## 사용 방법

```
QGIS 열기
→ 상단 메뉴 PestoMap 클릭 (또는 툴바 아이콘)
→ shp 파일이 있는 폴더 경로 지정
→ 실행 버튼
→ 끝
```

---

## 기능 (v0.1)

| 기능 | 내용 |
|------|------|
| shp 자동 로드 | 지정 폴더(하위 폴더 포함)의 shp 파일 전체 로드 |
| 색상 자동 적용 | 레이어명 키워드로 색상 자동 설정 |
| 지도 출력 | PDF / PNG (A3, 300dpi) |
| 스케일바·방위표 | 출력물에 자동 삽입 |

---

## 색상 수정 방법

`config.json` 파일을 메모장으로 열어서 HEX 색상값을 바꾸면 돼요. 코딩 불필요.

```json
"도로": {
  "fill_color": "#E0E0E0",   ← 이 값을 바꾸면 색상 변경
  "stroke_color": "#9E9E9E"
}
```

---

## 키워드 → 색상 매칭 기준

| 레이어명에 포함된 단어 | 적용 색상 |
|-------------------|----|
| 지적, 필지 | 연한 노랑 (연속지적도) |
| 도로 | 회색 |
| 하천, 수계 | 하늘색 |
| 녹지, 공원 | 연한 초록 |
| 용도지역 | 연한 보라 |
| 용도지구 | 연한 남보라 |
| 지하철 | 빨강 선 |
| 철도 | 갈색 선 |
| 그 외 | 연한 회색 |
